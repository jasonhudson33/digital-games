Prototype notes · Tiles are generated from one CSS recipe and a single --h hue per game, replacing ~250 lines of hand-tuned gradients. Hues are spread so no two alphabetically adjacent games sit within 40°. Player counts and durations marked with a dotted underline are estimates — the repo doesn't record them yet, which is the argument for a structured lib/games.js. Fonts load once via next/font in the real build; here they come from one preconnected stylesheet rather than three route-level @imports.
