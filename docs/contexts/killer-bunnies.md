# Killer Bunnies

Killer Bunnies owns the main deck, carrot market, Bunny Circle, hidden Magic Carrot and per-seat private views for two to eight players.

## Language

**Bunny Circle**: A player's protected set of bunnies.

**Magic Carrot**: The hidden winning carrot, secret until revealed.

**Card Catalog**: The Blue starter and Yellow booster content that forms the base game.

## Relationships

- The server holds the whole game; a seat sees only its own cards, and the Magic Carrot is not sent before reveal.
- A room needs two to eight players.

## Example dialogue

> **Dev:** "Does the client know which carrot wins?"
> **Domain expert:** "No, it is withheld until the reveal."
