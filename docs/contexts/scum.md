# Scum

Scum owns ranked card shedding, pile control, and between-round class trades.

## Language

**Class**: A player's rank earned from their finishing order.

**Pile**: The active set that must be matched in size and beaten in rank.

**Class Trade**: The mandatory card exchange between paired upper and lower classes.

## Relationships

- Finishing order assigns each player a **Class**.
- A new round waits for every required **Class Trade**.

## Example dialogue

> **Dev:** "Can the next round start before every **Class Trade** is submitted?"
> **Domain expert:** "No, all required exchanges resolve together."
